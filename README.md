# Гимназия 122 — город 17 чудес

Интерактивная сказка учеников 9А класса гимназии № 122 имени Ж. А. Зайцевой (Казань) к конкурсу стенгазет «#Мечтай!Действуй!Россия!». Подзаголовок проекта: «Мечтай! Действуй! Россия начинается с нас».

Сайт рассказывает 17 вымышленных историй о ценностях из пункта 5 Указа Президента РФ № 809. Реальная жизнь класса отделена от сказки: галерея показывает несколько событий нынешнего 9А, опубликованных гимназией в 2025 году, когда класс учился в 8А. Сайт дополняет стенгазету; бумажная работа 85 × 60 см, по условиям из задания, должна быть оформлена вручную.

## Запуск

Требуется Node.js 24 или новее и npm.

```sh
npm ci
npm run dev
```

## Проверки и сборка

```sh
npm run lint
npm test
npm run build
npm run preview
```

`npm run build` проверяет TypeScript и создаёт статическую версию в `dist/`. Приложение использует hash-маршруты, поэтому прямые ссылки на главы работают на GitHub Pages. Прогресс хранится только в `localStorage` этого браузера и может быть сброшен в журнале путешественника.

## Озвучивание сказок

Озвучка использует русские голоса, установленные в браузере или операционной системе, поэтому их звучание зависит от устройства. В главе можно выбрать доступный голос, послушать короткий пример и настроить темп; выбор сохраняется в `localStorage` этого браузера.

## Структура

- `src/content/chapters.ts` — истории, места, задания и обратная связь.
- `src/content/types.ts` и `validation.ts` — типы и проверка заданий.
- `src/App.tsx`, `src/styles.css` — интерфейс, карта, галерея, журнал, адаптивная верстка.
- `PHOTO_REQUESTS.md`, `PHOTO_STATUS.md` — запрос и состояние школьных фотографий.
- `posters/` — SVG-макет ватмана и QR-код; `POSTER_GUIDE.md` — ручной перенос концепции.
- `.github/workflows/deploy.yml` — проверки и GitHub Pages.

## Фото класса

В галерее размещены четыре фотографии из открытого канала гимназии; ссылки на исходные публикации указаны под снимками. Статус материалов и основание публикации описаны в `PHOTO_STATUS.md`.
