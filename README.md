# Гимназия 122 — город 17 чудес

Интерактивная сказка учеников 9А класса гимназии № 122 имени Ж. А. Зайцевой (Казань) к конкурсу стенгазет «#Мечтай!Действуй!Россия!». Подзаголовок проекта: «Мечтай! Действуй! Россия начинается с нас».

Сайт рассказывает 17 вымышленных историй о ценностях из пункта 5 Указа Президента РФ № 809. Реальная жизнь класса отделена от сказки: фото и подтверждённые события ещё не добавлены. Сайт дополняет стенгазету; бумажная работа 85 × 60 см, по условиям из задания, должна быть оформлена вручную.

## Запуск

Требуется Node.js 24 или новее и npm.

```sh
npm ci
npm run dev
```

## Проверки и сборка

```sh
npm run lint
npm test
npm run build
npm run preview
```

`npm run build` проверяет TypeScript и создаёт статическую версию в `dist/`. Приложение использует hash-маршруты, поэтому прямые ссылки на главы работают на GitHub Pages. Прогресс хранится только в `localStorage` этого браузера и может быть сброшен в журнале путешественника.

## Структура

- `src/content/chapters.ts` — истории, места, задания и обратная связь.
- `src/content/types.ts` и `validation.ts` — типы и проверка заданий.
- `src/App.tsx`, `src/styles.css` — интерфейс, карта, галерея, журнал, адаптивная верстка.
- `PHOTO_REQUESTS.md`, `PHOTO_STATUS.md` — запрос и состояние школьных фотографий.
- `posters/` — SVG-макет ватмана и QR-код; `POSTER_GUIDE.md` — ручной перенос концепции.
- `.github/workflows/deploy.yml` — проверки и GitHub Pages.

## Фото класса

Материалы не включены в публичную сборку. Снимки можно передать после получения согласия на использование и отдельного подтверждения публикации; до этого они не добавляются в сайт или репозиторий. См. оба файла о фотографиях.

## Публикация

Для проекта GitHub Pages в `vite.config.ts` задан путь `/gymnasium-17-wonders/`. Workflow на `main` выполняет lint, тесты, production build и deployment. Требуется включить Pages с источником GitHub Actions в настройках репозитория. Сайт считается опубликованным только после зелёного workflow и проверки URL.

## Источники и авторство

Точные названия ценностей сверяются с [Указом Президента РФ от 09.11.2022 № 809](https://www.consultant.ru/document/cons_doc_LAW_430906/). Параметры конкурса и срок сдачи в проекте взяты из предоставленного пользователем задания и отдельно не подтверждены на сайте организатора.
